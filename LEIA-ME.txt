VILA REAL FUTSAL — VERSÃO COM AUTENTICAÇÃO E BANCO CENTRAL

Arquivos:
- index_corrigido.html
- server.js
- package.json

1. REQUISITOS
- Node.js 18 ou superior.

2. INSTALAÇÃO
Na pasta dos arquivos, execute:
  npm start

Depois acesse:
  http://localhost:3000

3. SENHA INICIAL DO ADMINISTRADOR
Por padrão, o servidor cria o administrador:
  usuário: gleuber
  senha inicial: Opala77@2056

Para produção, defina uma senha diferente antes da primeira inicialização:
  Windows PowerShell:
    $env:ADMIN_INITIAL_PASSWORD="SuaSenhaForte@123"
    npm start

  Linux/macOS:
    ADMIN_INITIAL_PASSWORD='SuaSenhaForte@123' npm start

A senha não fica mais gravada no HTML/JavaScript do navegador. O servidor armazena apenas hash scrypt.

4. SEGURANÇA
- Login validado no servidor.
- Sessão em cookie HttpOnly.
- Senhas armazenadas com scrypt.
- /api/state exige sessão.
- Alterações são filtradas pelo servidor conforme as permissões do usuário.
- Personalização/layout global só pode ser alterada pelo Administrador.
- Senhas nunca são devolvidas ao navegador.

5. SINCRONIZAÇÃO
O servidor mantém um estado central em:
  data/state.json

Os clientes autenticados recebem atualizações por Server-Sent Events (SSE). Alterações de layout, permissões e dados são propagadas aos demais clientes.

6. PRODUÇÃO
Para publicar na internet, recomenda-se:
- HTTPS/reverse proxy (Nginx, Caddy ou equivalente).
- Banco de dados real (PostgreSQL/MySQL) no lugar de state.json.
- Backup automático.
- Variável ADMIN_INITIAL_PASSWORD configurada antes da primeira inicialização.
- Não expor a porta do Node diretamente à internet.

7. MIGRAÇÃO
Se já existir um state.json antigo com senhas em texto, o servidor faz uma migração automática para scrypt na primeira inicialização e remove os campos de senha em texto.
